# Premium Solan Real Estate Website

## Goal
Build a polished, content-rich multi-page demonstration website for a Solan-based real estate agency. The experience will feel distinctly Himachali and professional, prioritize enquiries and WhatsApp conversations, and clearly label all invented listings, reviews, statistics, and contact details as demo content.

## Visual Direction
- Use a warm white base with forest green, charcoal, muted sage, and refined beige accents.
- Pair an elegant editorial display face with a highly readable modern sans-serif body face.
- Generate a cohesive set of Solan/Himachal-inspired property images for the hero, listings, locations, categories, trust section, and call-to-action banner.
- Use spacious editorial layouts, restrained shadows, modest corner rounding, subtle textures, and strong photographic framing.
- Add purposeful motion: gentle image zoom, fade-up reveals, staggered cards, a floating property highlight, navbar compression, accordion transitions, and reduced-motion support.

## Shared Website Foundation
- Create a sticky desktop/mobile header, accessible mobile menu, consistent footer, floating WhatsApp control, breadcrumbs, enquiry calls-to-action, and reusable page intro sections.
- Add functional WhatsApp links with the requested pre-filled message.
- Use placeholder labels instead of inventing a real phone number, email, office address, opening hours, or map coordinates.
- Build responsive layouts for desktop, tablet, and mobile with touch-friendly controls and no horizontal overflow.

## Home Page
- Build the full photographic hero and premium Buy/Rent/Sell search interface.
- Add sample featured properties with rich listing details and filtering interactions.
- Add services, local trust, Solan-area coverage, property categories, about/statistics, four-step process, investment guidance, demo testimonials, FAQ accordion, full-width call-to-action, and enquiry form.
- Ensure forms and search controls provide useful client-side feedback without pretending to persist or submit data.

## Pages and Content
Create unique, useful pages for:
- `/properties`, `/properties-for-sale`, `/properties-for-rent`
- `/houses-for-sale-in-solan`, `/flats-for-sale-in-solan`, `/plots-for-sale-in-solan`, `/commercial-property-in-solan`
- `/real-estate-in-solan`, `/real-estate-agents-in-solan`, `/property-dealers-in-solan`
- `/services`, `/about`, `/contact`, `/locations`
- `/locations/solan`, `/locations/kandaghat`, `/locations/kumarhatti`, `/locations/dharampur`, `/locations/barog`

Use shared listing and editorial templates while giving every page its own H1, introduction, relevant content, imagery, breadcrumbs, internal links, and conversion action.

## SEO and Trust
- Add unique route-level titles, descriptions, Open Graph details, Twitter card metadata, and self-referencing canonical paths.
- Use semantic landmarks and heading hierarchy, descriptive alt text, lazy-loaded supporting images, and natural local terminology without keyword stuffing.
- Add RealEstateAgent/LocalBusiness structured data only with safe placeholder-aware fields; omit unknown address, phone, hours, website, and coordinates.
- Preserve crawler access in `robots.txt`.
- Defer a production sitemap until the final public domain exists; no preview or invented domain will be embedded.

## Verification
- Check the latest build diagnostics after implementation.
- Test navigation, mobile menu, search controls, FAQ, enquiry form, WhatsApp links, and representative content pages in the live preview.
- Visually review desktop and mobile screenshots for legibility, image loading, spacing, overlap, and responsiveness.
